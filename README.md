# OmniRoute AI Web Generator

A full-stack local AI orchestrator built with **React**, **Node.js (Express)**, and **OmniRoute AI Gateway** to instantly generate, structure, and preview web applications on the fly.

## 🚀 Features
- **Local AI Routing:** Integrates seamlessly with a local OmniRoute instance to route prompts to top-tier LLMs securely.
- **Dynamic Code Generation:** Translates user prompts and architectural templates into structured, renderable JSON codeblocks.
- **Live Sandbox Preview:** Features a secure real-time `iframe` sandbox to view generated website layouts instantly.
- **Modern Minimalist UI:** Styled with a sleek slate-and-amber dark mode theme using Tailwind CSS and Vite.

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, Cors, Dotenv
- **AI Gateway:** OmniRoute (Local AI Router)

---

## ⚙️ Getting Started Locally

### Prerequisites
- Node.js installed on your machine
- OmniRoute desktop application running locally
